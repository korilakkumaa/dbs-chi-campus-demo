# 拔萃男書院中國語文科 · 校園儀表板（示範）

溫暖紙面風格的教師用進度／班級／閱讀示範站。資料為前端 mock，無需後端。

## 線上預覽

部署後請開啟 GitHub repo 的 **Settings → Pages**，或看 Actions 產出的 Pages 網址。

（本機預覽：`npm run build && npm run preview`）

## 本機執行

```bash
npm install
npm run dev
```

## 示範帳號

| 帳戶 | 密碼 | 角色 |
|------|------|------|
| `admin` | `campus` | 管理員（全校＋分派） |
| `teacher` | `campus` | 吳綺琳 YLN（7G、7L、G9 EC、12L） |
| 各教師 initial 小寫（如 `yln`） | `campus` | 白名單教師 |
